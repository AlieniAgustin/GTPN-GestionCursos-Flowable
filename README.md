# GTPN-GestionCursos-Flowable
Sistema de automatización para la gestión de cursos de capacitación empresarial basado en Flowable. Incluye modelado BPMN, negociación de propuestas, preparación de recursos y dictado, con integración vía API REST/Java. Proyecto para la materia Gestión y Tecnologías de Procesos de Negocio.
